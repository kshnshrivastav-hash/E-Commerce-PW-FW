# Bug Report Template

| Field | Details |
|---|---|
| **ID** | BUG-001 |
| **Title** | Short, specific summary (what is wrong, where) |
| **Environment** | Browser and version, operating system, build or URL, date |
| **Severity** | Critical / High / Medium / Low (technical impact) |
| **Priority** | P1 / P2 / P3 / P4 (how soon to fix) |
| **Test case** | Related test case ID, if any |

## Severity guide

| Severity | Meaning | Example |
|---|---|---|
| Critical | Blocks a core flow or loses or corrupts data | Cannot complete checkout; wrong total charged |
| High | A major feature is broken, with no easy workaround | Cart count wrong after removing an item |
| Medium | A feature works with problems, or a workaround exists | Sort order wrong for one option |
| Low | Cosmetic or minor | Typo, small alignment issue |
